The unchanged injection fixture SHA256 is `176badbc44cefe435caf7a4cb60cdc452c524c87301d2fb8ef2bbd48df63b2d6`; source document hash is `579641e3e92e4e53244bbc60346f471fcd60fca52b73e1a99e35dd48b7f290c7`. Historical response was valid JSON with empty findings and a Turkish paraphrase of the clear renewal disadvantage in unresolvedIssues. No finding was rejected or removed by deduplication. Generation ended normally, 949 prompt tokens, 115 generated tokens; no context/output cap was reached.

Classification: **MODEL_SEMANTIC_FAILURE**. The pre-change original browser test reproduced the miss (`baseline/browser/integration.json`, nonzero exit). Five controlled direct follow-ups had three original-input recoveries and two neutral-control recoveries. Consequently **PROMPT_INJECTION_EFFECT is not causally established** by these repeats. The presence of attacker text alone is not proof of the precise mechanism. The best-supported observed error is misrouting a concrete disadvantage to uncertainty. `baseline/investigation.json` and raw requests preserve the evidence.

## Production changes and failed experiments

Only general source-identification alternatives and the risk system prompt changed in production. The prompt distinguishes untrusted source instructions from contractual obligations, concrete conditional disadvantages from genuinely indeterminate meaning, negation from affirmative obligations, and explicit data storage from payment/cancellation deadlines. It asks for complete source IDs and qualified evidence. No fixture lookup, keyword-forced finding, memorized quotation, changed model, second-pass inference, altered weights or loosened evidence validation was added.

The first shorter prompt did recover the injection example, but truncated the source ID in the ordinary renewal example. The validator correctly rejected it as UNKNOWN_CHUNK. All 55 native responses were schema valid, yet the live semantic suite was DEGRADED with one missed expected category and one evidence rejection. The first post-change P3 browser run stopped at the unchanged renewal assertion. Those records are preserved in `docs/evidence/p4/semantic/` and `final-browser/`; they are **failed experiments**, not final green results.

The final prompt is further condensed to fit a real 2322-character Reddit paragraph under the unchanged conservative UTF-8 input budget. The earlier prompt could not batch that paragraph (estimated 7232 vs input limit 6656); it was not truncated or quietly accepted. Both private real-evaluation runs are retained. Shortening increases usable source room but still cannot guarantee correct IDs or qualifications. The final risk prompt hash is recorded in each run. Protected grammar, provider, batching, evidence, score weights, Reflex and Page Agent implementation hashes are compared in the final audit.

## Real-contract and repeatability limits

Five official agreements were extracted. The preliminary eight-call experiment covered selected reference batches; the final 246-call fresh experiment attempted all 242 planned batches over the complete extracted snapshots. It completed 238 batches, with four output-budget failures and 757/780 chunks analyzed. Website completeness remains UNKNOWN/PARTIAL. Eight direct-reading draft annotations were frozen before real predictions. They remain PENDING_HUMAN_REVIEW; semantic support reviews are assistant drafts, never human/legal-expert approval. All metrics are PROVISIONAL and clause-level, not estimates of whole-document recall.

An exact quote can support a cap while its explanation falsely claims the cap applies without statutory exceptions. The real evaluation separately rejects such semantic matches. Other findings outside annotated chunks are visible and unscored; two observed Spotify concerns are recorded in `evaluation/annotations/unscored-concerns.json` (renewal despite easy cancellation and provider termination misclassified as changing terms). These references are not expanded after prediction merely to improve metrics.

`npm run test:semantics:p4` repeats the original injection source three times and protective clauses twice, with fixed model/context/temperature; it checks positive renewal, negation, protective conditions, contradictory sharing with consent and ambiguous storage. Categories, quotes and severities are compared separately. Temperature zero is not a deterministic-output guarantee. Scoring remains deterministic for identical verified findings; LLM interpretation can vary. Final observed failures and consistency counts are in `repeatability/summary.json`.

## Final observed outcomes

The unchanged original P3 fixture passed three repeated native runs and a dedicated real MV3 browser run after the final prompt. Positive, negated, qualified and contradictory-sharing cases passed; the ambiguous-storage case still produced UNCLEAR_DATA_RETENTION instead of the independently expected uncertainty result. The nine-call semantic suite therefore exits 1 / DEGRADED, despite 9/9 valid schemas. The repeated positive/negative/protective clauses each had one observed category/evidence/severity signature; this small experiment does not establish deterministic LLM behavior.

Full-reference sample: TP=4, FP=6, FN=4, micro precision 40%, recall 50%, F1 44.4%, PROVISIONAL. Source-qualified interpretation, ordinary foreseeability versus a referenced cap, and mandatory-law carve-outs remain problematic. A Dropbox refund finding was rejected for exact quotation mismatch (including nonbreaking-space differences); no whitespace normalization was silently applied. Four full-analysis batches returned truncated JSON at 1536 generated tokens twice each, giving eight invalid responses. Source prompts were not truncated; output-budget failures are explicit and never scored.

P3's original expected score 14 assertion remains intact and failed when the model produced 27. The test now records that failure and proceeds with unrelated UI checks only if complete, source-verified renewal evidence exists; its final nonzero outcome is preserved. All 12 measured P3 UI cases ran, including source highlighting, changed/closed source rejection, cross-tab isolation, popup restoration, safe-zero wording and unknown coverage. The final renewal report contains MEDIUM automatic renewal (14) plus MEDIUM cancellation difficulty (13), totaling 27. The legacy expectation assumed only 14. This is a changed finding set, not a changed score formula or arithmetic nondeterminism.

An earlier long experiment unexpectedly lost its processes; stale Ollama GPU metadata contradicted independent NVIDIA measurements. The subsequently user-reported canceled accidental shutdown attempt, unfinalized raw buffers and safe project-only restart are documented in p4-verification.md. Durable per-response/per-sample journals and exact-request cached resume now preserve future partial experiments. No old missing response was reconstructed.
